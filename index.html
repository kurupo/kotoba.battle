📖 「ことばバトル」遊び方

1. ことばバトルとは

「ことばバトル」は、60秒間でことばを作ってキャラクターを育て、その後のバトルで相手と戦うゲームです。作ったことばの文字数や条件によってHP・ATK・DEFが成長し、キャラクターごとの能力や特徴を活かして戦います。

バトルでは育てた能力を使い、基本的には相手のHPを0にすることを目指します。キャラクターによっては、通常勝利とは別の特殊勝利条件も存在します。

2. ことばのルール

育成フェーズでは、毎回表示される重複しない10種類のひらがなを使って、2文字以上のことばを作ります。表示されている同じ文字は、1つのことばの中で何度でも使用できます。

入力できる形はひらがな・小文字・長音記号「ー」を含む2文字以上です。濁点・半濁点は専用ボタンで付けることができ、「や・ゆ・よ・つ」は小文字ボタンで「ゃ・ゅ・ょ・っ」に変換できます。現在、長音記号は単語判定では有効ですが、文字パネルから長音記号を直接追加する専用操作はありません。

完成したことばは、許可語 → ゲーム補完辞書 → 日本語辞書の登録状況などをもとに判定されます。使用禁止語に指定されていることばは成立しません。一度成立したことばは、そのゲーム中にもう一度使用することはできません。

候補として表示されても、最終的には「この言葉で決定」を押した時点の単語判定によって成立・不成立が決まります。

3. ことば作成・育成フェーズ

制限時間は60秒です。基本の流れは、文字を選ぶ → ことばを作る → 単語判定 → しりとり判定 → 各種ボーナス判定 → ことば成立・ステータス成長です。成立後は新しい10文字が表示され、次のことばを作ります。10文字変更には5秒の再使用待ち時間があります。

文字数による共通成長：2文字はATK、3文字はDEF、4文字はHPが伸びやすく、5文字以上はHP・ATK・DEFのすべてが成長します。長いことばほど追加成長も大きくなります。

しりとり：成立したことばの最後の文字が「引き継ぎ文字」になります。次のことばをその文字から始めて成立させると、しりとり成功となり、通常の成長に加えてキャラクターごとのしりとりボーナスが発生します。

各種ボーナス：キャラクターによって、得意な文字数や特定条件で発生する固有の育成ボーナスがあります。詳しい発動条件・効果・数値については から確認できます。

ことば作成アシスト：入力中の文字から作れる候補を表示します。候補は5文字以上を優先し、その次に使用キャラクターの得意文字数を優先します。候補を押して自動入力する機能ではなく、作れることばを確認するための補助機能です。

4. 攻撃・防御・ダメージ・HITの仕組み

育成終了後は、育てたHP・ATK・DEFを使ってコマンド式のバトルを行います。通常攻撃は1HITとして扱い、攻撃側のATKと防御側のDEF・最大HPなどからダメージが決まります。

防御を選択すると、そのターンに受ける通常のダメージを軽減します。攻撃側のATKが防御側の有効DEF以上なら通常時より軽減率が小さくなり、下回っていればより大きく軽減します。ただし最低1ダメージは発生します。

鬼灯のHITと防御：防御した相手が鬼灯か桃真なら、鬼灯の連撃によるHITカウントは最初の防御で75%の確率で0になり、失敗時は維持されます。次の防御では50%の確率で0になり、失敗すると1増えます。桃真が防御する場合はお供1体につきキャンセル率が7%上がります。ネフェルの防御はHITカウントを必ず0にします。

HITは「何回の攻撃が当たったか」を数える単位です。通常攻撃は1HITですが、固有技などによって1回の行動で複数HITが発生する場合があります。キャラクター固有の効果や数値は で確認できます。

5. キャラクターと固有能力

キャラクターごとに、初期ステータス・性能傾向・固有能力・固有ボーナス・固有技・超・固有技・特殊勝利条件・独自システムが設定されています。同じ共通ルールでも、選んだキャラクターによって育て方や戦い方が大きく変わります。

各キャラクターの特性・能力・発動条件・具体的な数値などは から確認できます。

6. バトルの基本・ターンの流れ

育成が終了するとバトル開始です。各ターンは、「攻撃・防御・固有技・超・固有技」から行動を選択 → 両者の行動と効果を処理 → 勝敗判定 → 次のターンという流れで進みます。

バトルは同時選択方式です。行動は魅了の同時発動、魅了、三角結界、防御、その他の順で処理します。すでに選択された行動は、相手の処理によって途中でHPが0になっても同じターンに実行されるため、両者のHPが同時に0になることがあります。ただし連続攻撃は相手のHPが0になった時点で残りの攻撃を止めます。

固有技は使用回数・クールダウンなどの制限があります。固有技または超・固有技を使用した次の自分のターンは防御できません。魅了されると行動が通常攻撃に制限されますが、発動前に選んだ固有技・超・固有技の使用回数は消費されません。両者が同じターンに魅了を発動した場合は、互いの行動と魅了効果を打ち消しますが、超・固有技の使用権と魅了ゲージは消費します。

超・固有技：バトル中に固有技を1回以上使用し、さらに育成フェーズで「5文字以上のことばを1回成立」「ことばを20個以上成立」「しりとりを7回以上成立」のいずれかを達成すると、1試合に1回使用できます。

7. 勝利・敗北条件

通常勝利：相手のHPを0にすると勝利です。自分のHPが0になると敗北です。同じターンに両者のHPが0になった場合は引き分けです。

特殊勝利：鬼灯の6HIT、ネフェルの33ターン生存、桃真の真・四人共闘など、キャラクターごとに条件が異なります。33ターン目にネフェルが生存していれば、他の特殊勝利よりネフェルの条件を優先します。ネフェル同士が33ターン目に生存した場合は、残りHPの割合が高い方の勝利、同率なら引き分けです。そのほか同時に勝利条件が成立した場合は引き分けです。詳しい条件は で確認できます。
